## Código curso de prueba unitarias en .NET y C# con xUnit

Este repositorio contiene el código fuente y ejemplos prácticos del curso de pruebas unitarias en .NET y C# utilizando el framework xUnit.

### Estructura del repositorio

- **StringManipulation/**  
  Proyecto principal con lógica de manipulación de cadenas:
  - `StringOperations.cs`: Métodos para operaciones como verificación de palíndromos, eliminación de espacios y conversión de cantidades a palabras.

- **StringManipulation.Test/**  
  Proyecto de pruebas unitarias:
  - `StringOperationsTest.cs`: Pruebas unitarias para los métodos de manipulación de cadenas.
  - `UnitTest1.cs`: Ejemplo adicional de pruebas.
  - Reportes de cobertura generados con ReportGenerator (`coverage-report/`).

### Temas abordados

- Implementación de pruebas unitarias con xUnit.
- Pruebas de métodos para manipulación de cadenas.
- Uso de interfaces para facilitar el testeo y la inyección de dependencias.
- Generación y análisis de reportes de cobertura de código.
- Buenas prácticas en la organización de proyectos de pruebas en .NET.
